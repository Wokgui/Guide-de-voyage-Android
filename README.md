# Guide de voyage Android

Application Android autonome. Ce dépôt contient uniquement le code, les ressources visuelles et les fichiers de compilation. Le programme, les dates, les notes et les informations personnelles sont chargés depuis Supabase après connexion au compte autorisé. Aucun jeu de données personnel n’est livré dans l’APK.

Les versions Android sont disponibles dans les Releases. Installer les mises à jour par-dessus la version précédente. La signature de compilation utilise une clé externe fournie par WOKGUI_NATIVE_KEYSTORE.
